For parents and teachers

What each simulation leaves out

These simulations show how one control changes several results. They are not engineering tools. Each system shows three controls and five stages.

How to use this with a child or class

First ask for a prediction. Move one lever, name what changed, then try the fault. In watch mode, pause after each caption and ask what you would do next.

Your settings are not saved

There are no accounts, analytics, cookies, or saved profiles. A share link contains only the current system settings.
