# How It Runs: 5-minute browser simulators of everyday jobs and systems, built to explain 'what do you actually do?' to ki

Live: https://how-it-runs.sociobot.in — built by the Param Factory (`static-web`).

See `.factory/brief.json` for the researched problem this solves and `.factory/design.md` for the visual system.

## Develop

```
npm install
npm run dev
npm test
npm run build   # -> dist/
```
